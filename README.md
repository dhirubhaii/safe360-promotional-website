Safe360 Training Systems is a cybersecurity training company focused on immersive, browser-based awareness programs that help teams identify and respond to phishing and social engineering threats.

This repository contains the promotional website for Safe360 and its flagship product, PhishHook — a headset-free, browser-native 360° cyber awareness training experience built to simulate real workplace decisions in a realistic virtual office environment.

## Live site

- Promotional site: https://dhirubhaii.github.io/safe360-promotional-website/
- 360° prototype: https://dhirubhaii.github.io/phishhook/
- Full 3D simulation: https://dhirubhaii.github.io/phishhook/game.html

## Why this project matters

PhishHook is designed to turn passive cyber awareness training into measurable behavior change. Instead of static slides or text-heavy policies, the experience places employees in a simulated workplace where they must quickly evaluate suspicious emails, decide whether to report or delete them, and avoid a breach under time pressure.

## Key features

- Browser-based 360° training experience
- No VR headset or complex setup required
- Realistic phishing decision scenarios
- Time-pressure challenge loop with measurable scoring
- Immediate feedback for safe reporting and risky behavior
- Fully static site design for simple hosting and deployment
- Locally bundled assets for offline-friendly use

## Local development

This project is a static website and does not require a package manager or build process.

### Open directly in a browser

1. Open the project folder.
2. Double-click `index.html` or open it in a browser.
3. The site should render without any additional setup.

### Use Live Server in VS Code

1. Open the folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` and select **Open with Live Server**.
4. The page will open in a local preview.

### Example URL

For a repository named `safe360-promotional-website` owned by `dhirubhaii`, the site will typically be:

https://dhirubhaii.github.io/safe360-promotional-website/

> The first deployment may take a few minutes to appear after the workflow completes.
