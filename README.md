# Safe360 Training Systems

Promotional website for Safe360 Training Systems and its browser-based cybersecurity training product, PhishHook. The site is plain HTML, CSS, and JavaScript; it has no build step.

## Run locally

Open `index.html` directly, or use the Live Server extension in VS Code.

## Publish with GitHub Pages

The included GitHub Actions workflow deploys the site whenever you push to `main`.

1. Push the project files to a GitHub repository on the `main` branch.
2. In the repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source.
3. Open the **Actions** tab and wait for the Pages deployment workflow to finish.
4. The published address appears under **Settings → Pages**. For a repository named `safe360-promotional-website` owned by `dhirubhaii`, it will be `https://dhirubhaii.github.io/safe360-promotional-website/`.

The first deployment can take a few minutes. The PhishHook demo links open the separately hosted product; the office image is served by Unsplash.
